# oxml 0.0.11

Release preparation dated 2026-10-17. The suite is not yet cleared for
publication; see the [lockstep readiness assessment](0.0.11-readiness.md).

## Highlights ⭐️

* **Parsing limits cover allocation boundaries**: DTD nesting is bounded separately, node budgets include attributes and namespace nodes, and streaming checks complete as well as incomplete constructs. `Limits::strict()` caps both source and decoded document bytes at 8 MiB.
* **Untrusted XPath evaluation can use a per-call budget**: `EvalContext::with_limits` bounds work, intermediate node sets and strings. Compilation additionally bounds source bytes, syntax nodes and function arguments. Existing unbounded evaluation APIs retain their behavior.
* **Mutation and rendering preserve round trips**: namespace bindings and document-level text are validated before mutation, `try_to_xml` reports incomplete or unrepresentable documents, and XPath root operands retain their grouping when rendered.
* **Rust 1.89.0 and verified registry artifacts**: the MSRV rises from 1.86.0. Release attestations use the downloaded registry archive after checksum and source-commit checks; conformance tooling uses RustCrypto SHA-256 0.11.1, without adding a default parser runtime dependency.

## Upgrade notes

- Rust 1.89.0 or newer is required. Pre-0.1 releases may break API,
  as documented in the [MSRV policy](../MSRV-AND-DEPRECATION.md).
- Exhaustive matches on `EvalError` must handle `LimitExceeded`.
  Existing infallible evaluation remains unbounded; use
  `XPath::evaluate_with` and a limited `EvalContext` for untrusted queries.
- Parsing profiles now include `max_input_bytes`, `max_document_bytes`
  and `max_dtd_depth`. Source and decoded sizes remain unbounded under
  the default profile; the strict profile caps each at 8 MiB.
- Deep DTDs and expressions that exceed compilation storage limits
  are rejected. Node limits now count the document root, attributes,
  namespace nodes, comments and processing instructions consistently.
- Namespace mutations and non-whitespace text outside the document
  element that were previously accepted may now return an error.
  `SerialiseError::NoRootElement` reports an incomplete document.
- Canonical XPath text can change where parentheses are required or
  decimal literals overflow to infinity. Infinity now renders as a
  fixed overflowing decimal, preserving the compiled numeric node rather
  than introducing division. Rebuild caches keyed by rendered expressions.

## Verification and release status

The fuzz policy permits NCSA only for libfuzzer-sys 0.4.13; it does not
extend the runtime license allowlist. Security CI checks both graphs.

The [changelog](../../CHANGELOG.md#0011---2026-10-17) contains the full
change list. The core's local gate, package inspection and dependency
checks must pass on the final release commit; CI must be rechecked
after the release-preparation commit is pushed.

Publish `oxml` before `xmlschema`, and publish `oxml-json` before
`oxml-lsp`. The complete dependency order is in
[RELEASING.md](../RELEASING.md). No tag or registry publish is part of
this preparation. The release workflow generates the merged-PR list,
asset checksums and comparison link from the actual published artifacts.
