# 0.0.10

The release where the bounds became true. An audit of 0.0.9 found
that `XPath` expressions were not bounded by `Limits`, that `XPath`
positional predicates diverged from the 1.0 specification, that the
mutation API could leak and corrupt the arena, and that streaming
memory was bounded only for well-behaved input. This release fixes
the first three, hardens the parsing core, and moves the release
pipeline to trusted publishing with signed, attested artifacts.

## Highlights ⭐️

* **Every limit is enforced, including the `XPath` ones**: `XPath::compile_with_limits` applies `max_xpath_depth` and `max_xpath_operators`, which were documented and never read. An expression of a hundred thousand unary minuses aborted the process; it now returns an error. The DTD parser and the streaming reader gained their own bounds (`max_dtd_bytes`, `max_pe_expansion`, `max_construct_bytes`).
* **`XPath` 1.0 as specified**: predicates apply per context node, so `//row/cell[1]` returns the first cell of every row; reverse axes count from the context node; `<`, `>`, `!=` on node-sets are existential; filter expressions `(//a)[1]` and variables `$x` parse and evaluate.
* **A mutable tree you can trust**: appending children is amortised O(1) in memory (10,000 children retained 538 MB, now a few hundred KB), removed slots are never freed twice, names and text are validated on the way in, namespaced names created through the API are declared on the way out, and node-sets follow document order after edits.
* **Parsing core hardened**: the entity-validation cache no longer clones the namespace stack per reference (711 ms to 8 ms on the audit probe), the DTD is no longer cloned per entity, `<?xml-stylesheet ...?>` can no longer impersonate the XML declaration, duplicate `xmlns` declarations are rejected, and wide elements no longer pay a quadratic duplicate-attribute scan.
* **Release engineering to L3**: crates.io Trusted Publishing instead of a stored token, the tag's signature verified against `.github/allowed_signers`, the `.crate`, a CycloneDX SBOM and checksums attached to every release with SLSA provenance, `Cargo.lock` committed and every CI build `--locked`, a persistent fuzz corpus, and a per-function complexity ratchet.

## If you are upgrading

**`XPath::compile` is stricter.** The default budget allows 10,000
operators and a nesting depth of 256. An expression over either now
fails to compile instead of risking a stack overflow at evaluation.
Pass `Limits::permissive()` to `compile_with_limits` for expressions
you wrote yourself and trust.

**Positional predicates return more nodes.** `//a[1]` used to return
the first `a` in the document; it now returns the first `a` child of
every parent, as the specification says. To get the first match in
the whole document write `(//a)[1]`, which now parses.

**`!=` and the relational operators on node-sets are existential.**
`//a != 'x'` is true when any `a` differs from `x`. `not(//a = 'x')`
is the form that means "no `a` equals `x`".

**`number()` follows the `XPath` grammar.** `number('1e5')`,
`number('+1')` and `number('Infinity')` are NaN. `sum()` is NaN when
any node is not a number, instead of silently skipping it.

**`Expr` has new variants.** `Expr::Chain`, `Expr::Filter`,
`Expr::PathFrom` and `Expr::Variable`. Code that matches on `Expr`
exhaustively needs new arms.

**The mutation API rejects what it used to accept.** A child appended
to a text node, a second element under the document root, an invalid
name, text with a character XML forbids, and removing the root are
all errors now. They produced output the parser could not read.

**Two more duplicate-attribute errors.** `<a xmlns:p="u1"
xmlns:p="u2"/>` and `<a xmlns="u1" xmlns="u2"/>` are rejected, as the
`WFC: Unique Att Spec` requires.

## Added

- `XPath::compile_with_limits`, `XPath::compile_with_namespaces_and_limits`.
- `XPath::evaluate_with` and `evaluate_from_with`, taking an
  `EvalContext` of variable bindings and returning `Result`.
- `Expr::Chain`, `Expr::Filter`, `Expr::PathFrom`, `Expr::Variable`;
  `Display` for `Expr` and `XPath` rendering canonical unabbreviated
  `XPath`.
- `Limits::max_dtd_bytes`, `Limits::max_pe_expansion`,
  `Limits::max_construct_bytes`.
- `Document::declare_namespace`, `insert_at`, `set_text`,
  `append_comment`, `append_pi`, `detach`, `text_content`,
  `attribute_ns`, `document_order`, `descendants_of`, `nodes`,
  `compact`, `write_xml_to`, `range`; `Builder::child_ns`.
- `scripts/check-complexity.py` and `complexity-baseline.tsv`.
- `.github/allowed_signers`, `CITATION.cff`, `CODEOWNERS`, issue and
  pull-request templates, `.compliance.yml`.
