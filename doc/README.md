# Documentation

`doc/` documents the **decisions**. The
[rustdoc](https://docs.rs/oxml) documents the **API**, and the two do
not duplicate each other.

Every ```rust block in this directory is compiled and run as a test by
`crates/oxml/tests/doc_examples.rs`, generated by
`scripts/generate-doc-tests.py` and regenerated in CI. Code here is
checked, not illustrative.
